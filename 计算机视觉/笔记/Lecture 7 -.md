# Lecture 7 图像分割 学习笔记

## 一、什么是图像分割

### 1. 基本概念

图像分割（Segmentation）是指：

- 将一幅图像划分为多个区域
    
- 每个区域由一组像素组成
    
- 这些区域通常对应不同物体、不同部分或不同语义区域
    

### 2. 分割的目的

分割的目标是：

- 简化图像表示
    
- 让图像更有意义
    
- 便于后续分析、识别和理解
    

### 3. 二值分割

二值分割是分割的特殊情况，只分成两类：

- 前景 foreground
    
- 背景 background
    

---

## 二、本章内容框架

Lecture7 主要包括三类方法：

### 1. 基于灰度的分割

- Thresholding 阈值法
    
- Watershed 分水岭算法
    

### 2. 基于聚类的分割

- K-means 等聚类方法
    

### 3. 基于活动轮廓的分割

- Snake 蛇形模型
    
- Level Set 水平集
    

---

# 三、基于阈值的分割 Thresholding

## 1. 基本思想

阈值分割只考虑像素值，不考虑复杂的空间关系。

给定阈值 (T)：

- 大于 (T) 的像素归为一类
    
- 小于 (T) 的像素归为另一类
    

本质上就是根据灰度值把图像分成前景和背景。

---

## 2. 全局阈值 Global Threshold

### 思想

整张图只使用一个统一阈值 (T)。

适用于：

- 前景与背景灰度差异明显
    
- 图像光照比较均匀的情况
    

### 求全局阈值的迭代方法

步骤如下：

1. 先选一个初始阈值 (T_0)
    
2. 按照 (T_0) 把图像分成前景和背景
    
3. 计算前景均值 (\mu_f) 和背景均值 (\mu_b)
    
4. 更新阈值：  
    [  
    T_i = \frac{\mu_b + \mu_f}{2}  
    ]
    
5. 重复直到阈值不再变化
    

### 优点

- 简单
    
- 易实现
    
- 速度快
    

### 局限

全局阈值在以下情况效果不好：

- 前景和背景灰度接近
    
- 图像亮度不均匀
    
- 存在阴影或局部光照变化
    

---

## 3. 局部阈值 Local Thresholding

### 思想

将图像划分成多个小区域，对每个区域分别求阈值。

### 适用情况

适合：

- 光照不均匀
    
- 不同位置亮度背景不同的图像
    

### 本质

局部阈值法把一个全局问题拆成多个局部问题。

### 优缺点

优点：

- 比全局阈值更适应局部亮度变化
    

缺点：

- 分块大小不好选
    
- 太大则局部适应性不够
    
- 太小则容易受噪声影响
    

---

## 4. 最优阈值 Otsu 大津法

### 核心思想

自动选择一个阈值，使得：

- 类内方差最小
    
- 等价地，类间方差最大
    

### 理解

若用阈值把图像分成两类：

- 每一类内部应尽量一致
    
- 两类之间应尽量区分开
    

因此 Otsu 的目标就是找一个最优分割点。

### 特点

- 不需要人工设阈值
    
- 适合双峰直方图图像
    
- 仍然属于阈值法，因此也受光照和噪声影响
    

---

# 四、分水岭算法 Watershed

## 1. 基本思想

分水岭算法把灰度图看成一个地形图：

- 灰度低的地方看成山谷
    
- 灰度高的地方看成山峰
    

然后想象从每个山谷开始灌水：

- 水位逐渐升高
    
- 当两个盆地的水相遇时，在交界处筑坝
    
- 最终这些坝就是区域边界
    

---

## 2. 特点

分水岭是一种基于区域地形结构的分割方法，不再只是简单按阈值切割。

---

## 3. 直接应用的问题

如果直接在原灰度图上做分水岭，往往容易出现：

- 过分割
    
- 得到很多细碎小区域
    

原因是：

- 原图中存在大量噪声和局部小波动
    
- 这些小波动会形成许多小盆地
    

---

## 4. 改进方法

### （1）先平滑再分水岭

先对图像做模糊处理，可以减少噪声引起的过分割。

### （2）距离变换 + 分水岭

常用于分离粘连目标：

- 先得到前景区域
    
- 做距离变换
    
- 每个目标中心形成峰值
    
- 再做分水岭，将粘连目标分开
    

### 应用特点

分水岭特别适合：

- 细胞分割
    
- 颗粒分离
    
- 粘连物体分离
    

---

# 五、基于聚类的分割 Clustering-based Segmentation

## 1. 基本思想

把像素看作样本，根据它们的相似性分组：

- 相似的像素归到同一类
    
- 不同的像素归到不同类
    

---

## 2. 聚类的定义

聚类属于无监督学习，其目标是：

- 簇内距离最小化
    
- 簇间距离最大化
    

也就是：

- 同一类内部尽量相似
    
- 不同类之间尽量不同
    

---

## 3. 聚类方式

PPT 提到了两类思想：

### 聚合聚类 Agglomerative

- 从单个像素开始
    
- 逐步合并成簇
    

### 分裂聚类 Divisive

- 从整张图开始
    
- 逐步分裂成多个簇
    

---

## 4. K-means 聚类

### 基本思想

K-means 是最常见的聚类分割方法。

特点：

- 需要事先指定簇数 (K)
    
- 每个簇对应一个中心 centroid
    
- 每个点归到距离最近的中心
    

### 算法步骤

1. 初始化 (K) 个中心
    
2. 将每个像素分到最近的中心
    
3. 根据当前分类结果更新中心
    
4. 重复执行，直到结果稳定
    

### 图像分割中的特征向量

每个像素可以用以下特征表示：

- 灰度
    
- 颜色
    
- 纹理
    
- 空间位置
    
- 它们的组合
    

例如：

- 只用颜色：按颜色分割
    
- 用颜色 + 位置：既考虑颜色，也考虑空间连续性
    

### 优点

- 思路清晰
    
- 实现简单
    
- 可扩展到多种特征
    

### 缺点

- 需要预先指定 (K)
    
- 对初始中心敏感
    
- 可能把空间上不连通但颜色相似的区域分到一起
    

---

## 5. SLIC 超像素

SLIC 是一种基于聚类思想的超像素方法。

作用：

- 将图像分成很多小而连贯的区域
    
- 作为后续识别、分割、图模型处理的基础
    

---

# 六、活动轮廓 Active Contours

## 1. 基本思想

将分割看成一条曲线不断变形的过程：

- 先给定初始轮廓
    
- 定义能量函数
    
- 通过最小化能量使轮廓逐渐逼近目标边界
    

### 特点

- 能得到比较平滑的轮廓
    
- 本质是一个优化问题
    
- 常用方法有 Snake 和 Level Set
    

---

# 七、Snake 蛇形模型

## 1. 轮廓表示

Snake 用一组离散控制点表示轮廓。

也就是说：

- 轮廓是一串点连接形成的曲线
    
- 每次迭代时，每个点可以在邻域内移动
    
- 整条曲线逐步贴近目标边界
    

---

## 2. 能量函数

Snake 的总能量由两部分构成：

### （1）内部能量 Internal Energy

作用：

- 约束轮廓自身形状
    
- 使轮廓平滑
    
- 具有低曲率
    
- 保持弹性
    
- 也可加入已知形状先验
    

### （2）外部能量 External Energy

作用：

- 让轮廓靠近图像中的结构，如边缘
    
- 通常希望边缘处能量更低
    

---

## 3. 外部能量

常见定义方式：

[  
E_{\text{external}} = -(G_x(I)^2 + G_y(I)^2)  
]

其中：

- (G_x(I))、(G_y(I)) 是图像在 x、y 方向的梯度
    
- 梯度越大，表示边缘越明显
    
- 因为取负号，边缘处能量更低，轮廓会向边缘靠拢
    

---

## 4. 内部能量

### （1）弹性约束

约束相邻控制点间距变化不要太大。

### （2）曲率约束

惩罚轮廓的剧烈弯折，使轮廓更加平滑。

### 作用

内部能量平衡外部能量的影响，防止轮廓被噪声边缘吸引而变得锯齿化。

---

## 5. Snake 的问题

如果弹性能量定义不合理，可能出现：

- 轮廓不断收缩
    
- 最终塌缩成一个点
    

改进方式：

- 用相邻点与平均距离的偏差来定义弹性项
    
- 避免无限收缩
    

---

## 6. 处理缺失边缘

Snake 的平滑和低曲率偏好使它在边缘不完整时仍能得到较连续的轮廓。

这比单纯边缘检测更鲁棒。

---

## 7. 形状先验 Shape Prior

如果目标形状有明显规律，可以从一组训练样本中建立统计形状模型，并加入能量函数中作为额外约束。

作用：

- 提高弱边界情况下的稳定性
    
- 防止轮廓跑偏
    

---

## 8. Snake 的优缺点

### 优点

- 复杂度较低
    
- 容易引入先验知识
    
- 可处理开曲线和闭曲线
    

### 缺点

- 对初始轮廓敏感
    
- 不能自然处理拓扑变化
    
- 参数和采样规则影响结果
    

---

# 八、Level Set 水平集

## 1. 基本思想

Level Set 不直接表示曲线，而是用一个函数 (\phi(x,y)) 表示轮廓。

其中：

- (\phi(x,y)=0) 的位置就是轮廓
    
- 这条曲线称为零水平集 zero level set
    

---

## 2. 与 Snake 的区别

### Snake

- 显式表示轮廓
    
- 轮廓是一串控制点
    

### Level Set

- 隐式表示轮廓
    
- 轮廓是函数的零水平集
    

### 优势

Level Set 可以自然处理：

- 轮廓分裂
    
- 轮廓合并
    
- 拓扑变化
    

---

## 3. 带符号距离函数 Signed Distance Function

常用带符号距离函数表示 (\phi)：

- 在轮廓内部取负值
    
- 在轮廓外部取正值
    
- 在轮廓边界上取 0
    
- 绝对值表示到边界的距离
    

这样可直观表达轮廓内外关系。

---

## 4. 水平集演化

水平集通过速度函数 (F) 控制演化。

不同速度函数会导致不同的分割行为。

---

## 5. 几种典型演化方式

### （1）Constant Speed 常数速度

轮廓以恒定速度扩张或收缩。

特点：

- 简单
    
- 但无法自动在边界处停下
    

---

### （2）Mean Curvature Flow 平均曲率流

速度由曲率决定。

效果：

- 轮廓趋于更平滑
    
- 可去掉尖角和细碎结构
    

---

### （3）基于梯度的速度

根据图像梯度设计停止函数 (g(I))：

- 梯度越大，(g(I)) 越小
    
- 轮廓越靠近边缘，速度越小
    
- 最终在边界附近停下
    

---

## 6. Geodesic Active Contour 测地活动轮廓

该模型综合了多种因素：

- 曲率平滑项
    
- balloon term：控制轮廓膨胀或收缩
    
- attachment term：帮助轮廓吸附到边界上
    

其本质是：

- 既让轮廓能主动传播
    
- 又能在边界附近停下
    
- 同时保持平滑
    

---

# 九、区域型水平集 Chan-Vese 模型

## 1. 提出原因

边缘型 Level Set 的问题：

- 当边界很弱时效果差
    
- stopping function 在边界处未必为 0
    
- 轮廓可能穿过真实边界
    

因此提出区域型 Level Set，即 Chan-Vese 模型。

---

## 2. 核心思想

Chan-Vese 模型不依赖边缘，而依赖区域统计特性：

- 轮廓内部区域像素值接近均值 (C_1)
    
- 轮廓外部区域像素值接近均值 (C_2)
    

通过寻找合适轮廓，使得：

- 内部像素尽量接近 (C_1)
    
- 外部像素尽量接近 (C_2)
    

本质上类似：

- 类内方差最小化
    

---

## 3. 能量构成

Chan-Vese 模型中除了区域拟合项，还会加：

- 轮廓长度项
    
- 区域面积项
    

作用：

- 保证轮廓平滑
    
- 控制分割区域大小
    
- 提高稳定性
    

---

## 4. 优点

- 不依赖清晰边缘
    
- 对弱边界更有效
    
- 更适合一些医学图像或低对比度场景
    

---

## 5. 与边缘型 Level Set 的比较

### 边缘型 Level Set

- 依赖梯度
    
- 需要边界较明显
    
- 可能越过目标边界
    

### Chan-Vese

- 不需要边缘检测
    
- 更依赖区域统计
    
- 对模糊边界更稳

# 十、整章总结

## 1. 三大类分割方法

### （1）基于灰度

- Thresholding
    
- Watershed
    

### （2）基于相似性

- Clustering / K-means
    

### （3）基于轮廓演化

- Snake
    
- Level Set
    
- Chan-Vese
    

---

## 2. 方法对比总结

### 阈值法

- 简单快速
    
- 适合前景背景灰度差异明显的场景
    

### 分水岭

- 基于地形结构
    
- 适合粘连目标分离
    
- 易过分割
    

### K-means

- 基于像素相似性
    
- 能利用颜色、纹理、位置等特征
    
- 需指定簇数 (K)
    

### Snake

- 显式轮廓模型
    
- 可加入平滑和形状先验
    
- 对初始轮廓敏感
    

### Level Set

- 隐式轮廓模型
    
- 可自然处理拓扑变化
    
- 更灵活、更强大
    

### Chan-Vese

- 基于区域统计
    
- 不依赖强边缘
    
- 对弱边界更有效

# 十一、复习时最该记住的要点

## 1. 图像分割定义

将图像划分成多个有意义区域。

## 2. Otsu

通过最小化类内方差、最大化类间方差选择最佳阈值。

## 3. Watershed

把图像看作地形图，通过灌水和筑坝形成区域边界。

## 4. K-means

通过像素特征相似性进行无监督聚类分割。

## 5. Snake

通过最小化内部能量和外部能量，使轮廓贴合目标边界。

## 6. Level Set

用函数的零水平集表示轮廓，可自然处理拓扑变化。

## 7. Chan-Vese

区域型水平集方法，不依赖边缘检测。
